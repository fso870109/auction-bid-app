# 拍賣標貨助手

給菜商在果菜拍賣市場現場使用的標貨工具（離線也能用的手機網頁 App）。

- 場次：水果場最早，接著上半場、下半場；場次按鈕各有明顯顏色
- 抄號：大鍵盤快速輸入貨號，四碼自動存；品項依桃農近一年交易量排序，太冷門的不出現在按鈕裡（可搜尋）；番茄可標大／中／小；香菇類在上半場大宗第一台；芋頭、蒜、青花、薑、薯類、花椰菜、球莖甘藍、竹筍、萵苣莖、蓮藕、蘆筍、牛蒡在下半場瓜果
- 備註：記下預計要批的品項，獨立全畫面編輯，開始新的一天也不會清掉；可從昨天買過的快選挑，看貨時預設收合。畫面正下方有大顆「返回」鈕，方便單手按
- 舉牌：全螢幕粗體顯示承銷人代號給拍賣員看
- 追蹤：三台同時跟上進度，快到了會振動
- 結果：一鍵標到／沒標到，可複製或分享清單
- 兩人同步：在設定建立房間，用「複製邀請連結」或畫面中的 QR 碼分享給另一支手機；也可貼上邀請碼加入。一個房間最多兩支手機，第三支要經建立者允許。沒加入房間時，資料仍只存在自己手機

沒加入房間時，資料只存在你的手機。建立房間後，把邀請連結或 QR 碼給另一支手機（請貼上完整邀請碼，不要只用畫面上的四字簡稱）。加入後，抄號、標到、流標、優先、備註、台別和進度會同步到同房的另一支手機；舉牌用的承銷人代號、顏色和振動設定不會同步。一個房間最多兩支已核准的手機；第三支要先經建立者在設定裡允許。舊的 6 位數房號已無法讓新手機加入，請由其中一支手機在設定裡「更新邀請」後再分享。
